About The Project

PCDex+, formally GPX+ Shiny Tracker, is a personal project that I started for myself years back, but in 2021 it was shared to the public! It's a tool designed to help players of Global PokédeX Plus have an easier time cataloging their Shiny Pokémon they obtain! My goal is to make the project have the information of a Pokédex with the appearance of a Pokémon PC, hence the name of the project! PCDex+ is subject to occasional updates!

Over the years it has gotten many updates, with that brought neat things and overall design improvements! Seriously, the day the project got shared to the public, Cycloneblaze, overnight, made a drastic improvement to the project by implementing JavaScript features that allowed you to mark Pokemon as "owned" with a single mouseclick instead of the original intended method of having people edit through HTML. That was so cool to me! I'm still very thankful for it! Community members Rookie Roo and Isla de Monte Cristo have also helped with other challenges of the project! I think of PCDex+ as a community project, so any suggestions or contributions to updates are welcome!

Files & Download

The project is hosted on GitHub. There you'll see a list of files in the repository.


Files And Descriptions
  • Getting Started.html
  • A document to help a new user get accustomed to how PCDex+ works. It also contains all the latest and previous update information.
  • PCDex+ Basic.html
  • For people who keep things simple: you already know it's impossible to obtain every Shiny Arceus! This challenge cuts down on a significant amount of entries and you should use it if you're aiming on obtaining mostly one Shiny per Evolution line.
  • PCDex+ Standard.html
  • For people who want a real tough challenge: having a Shiny Standard Living Pokédex. This challenge doesn't contain minor gender differences and you should use it if you're aiming on obtaining one Shiny per Pokédex entry.
  • PCDex+ Ultimate.html
  • For people who are taking on the toughest challenge: having a Shiny Ultimate Living Pokédex. This challenge has all gender differences included and you should use it if you're planning on going above and beyond for your Shiny collection.
  • Style.css
  • This goes alongside the .html files. Essentially, it holds the design and makes everything look pretty.
  • Cheats.js
  • A Javascript file. This gives you the ability to mark every Shiny as obtained with the click of a button! Could be useful for specific viewing purposes such as the Poké Hunt. You'll also be able to reverse back to your previous progress or completely wipe your progression.
  • ClickProgress.js
  • A Javascript file made by Cycloneblaze. This gives you the option of easily adding the shinies you've collected with a mouse click over using manual code. It's compatible with all three versions of PCDex+.
  • Filters.js
  • A Javascript file. This gives you the ability to toggle on and off filters to better search for a specific group of Pokémon. It's compatible with all three versions of PCDex+.
  • SearchBar.js
  • Another Javascript file made by Cycloneblaze. This adds in a search bar which allows you to search for Pokémon in the list by their name and jump to them. It's compatible with all three versions of PCDex+.
  • Summary.js
  • A Javascript file. This gives extra help controlling the display of the Summary when hovering over Pokémon. It's compatible with all three versions of PCDex+.
  • Theme.js
  • A Javascript file. This gives you the ability to switch between the Sun and Moon themes. It's compatible with all three versions of PCDex+.
  • README.md
  • A file created by GitHub. It contains all the latest and previous update information and download links.

How do I edit PCDex+ with JavaScript?

This is the prefered method of adding in your shiny collection! Your data will be stored in your browsers cache, but removed if you clear it!

  • Only step!: Open your challenge of choice in your browser.
  • Next, click on the icons you own to mark them as "owned". You can click the icon again to mark it as "notown". The script updates the progress bar for you automatically.

    • Now let's backup your JavaScript changes to your HTML file so you have protection if your cache clears!

  • Step 1: Clicking the Pokémon icons you own.
  • In this example I marked that I owned the entire Bulbasaur evolution line, this includes: Bulbasaur, Ivysaur, Venusaur, Mega Venusaur, and Gigantamax Venusaur. Now that I clicked them on my browser their status has changed from "notown" to "own".
  • Step 2: Inspect element
  • In order to replace this new data in our HTML file we will need to use the "Inspect" feature that's built into our browser. Right-click on empty space inside the Living Pokédex section that contains all the Pokémon icons and then click "Inspect".
  • It will then bring up something like this at the bottom of your screen. You'll need to find and highlight 
    <main id="mark">
  • Final Step: Copying the JavaScript changes
  • Right-click on this highlighted section > Copy > Outer HTML.
  • This is all the data displayed in the PC icon section, every Pokémon. Once you copy the code with the "Inspect" feature you will need to replace the code in your HTML file if you want a hard save. This would need to be pasted over the start of the same section you copied. All you are doing is replacing the old data.
How do I edit PCDex+ with HTML?

It's highly recommended you update your collection through JavaScript instead, It's much easier!

  • Step 1: Choosing a Text Editor.
  • Notepad on Windows or TextEdit on Mac work just fine, but you can download a better editor such as Atom, Notepad ++, Sublime Text, or Visual Studio Code.
  • Step 2: Updating the Pokémon you own.
  • Now that you have your text editor, open your challenge of choice in the program. Once you do that, you'll see something like this.
  • The only thing you need to worry about changing is the img class. By default, every img class is marked as "notown". If you want to register as owned, change the img class to "own".
  • Step 3: Updating your total completion progress.
  • Close to the top of the HTML pages you'll find the "nav". This is where you'll find your collection progress of each Generation.
  • The two important codes are "value" and "title". The value visually raises your progress percent, and the title tells you how many Shinies you own when you hover over the progress bar. By default, every value is marked as "0" and the titles are marked as "0/#". # represents the total number of Pokémon in the respective region. So, if you hatched a Shiny Bulbasaur, you can set both 0's to 1.
  • Finished!: An example of the final result!
  • In this example, I marked that I owned all of the Pokémon in PC Box 1. I also changed the appropriate commands for the progress bar so that it visually updates.
  • As you can see, the Pokémon are now full color compared to the rest of the icons, and the progress bar has been updated. So now when I hover over the progress bar I get the desired result!
How do I search for Pokémon?

Just type in the box and click the Find it! button, and you should be taken right to the Pokémon!

  • The search box looks for the first Pokémon whose name starts with what you wrote. It also works in lowercase. So if you type "mag", or "Mag", Magnemite will be shown for you, but not Magneton, Magnezone or Magearna. But if you type "mage", you'll get right to Magearna! It's like the search text always has a wildcard character on the end.
  • You do need to know a Pokémon's name, including form. By typing "altaria" you can get to Altaria but also Altaria [Mega], since it has the same Pokédex number, so it's right nearby. But you won't get to Altaria [Constellation], or Zhenyin, because they are listed under Novelty Pokémon and not Generation III. You could find those two by typing "altaria [c", or just "zh".
